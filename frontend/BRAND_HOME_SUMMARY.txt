USER FLOW:
==========
1. Brand logs in → Redirected to /brand-home (BrandWelcomePage)
2. Welcome page loads with:
   - Header: "Welcome to UGCad, [Brand Name]! 👋"
   - Profile icon in top-right corner
3. Click profile icon → Dropdown menu appears on RIGHT side
4. Dropdown shows:
   - User info (name, "Approved Business" label)
   - All 10 navigation tabs:
     * Brand Dashboard
     * Post a Brief
     * Creator Bids (with badge)
     * Browse Creator
     * All Campaigns (with count)
     * Work Review
     * Messages
     * Manage Shipment
     * Wallet
     * Settings
   - Logout button at bottom
5. Click any tab → Navigate to that dashboard section
6. Click outside dropdown → Menu closes
