UGCad Backend Setup Instructions

1. Install dependencies:
   npm install

2. Create .env file:
   cp .env.example .env

3. Configure MongoDB URI in .env

4. Start development server:
   npm run dev

5. API will be available at http://localhost:5000

API Endpoints:
- POST /api/gigs - Create new gig
- GET /api/gigs - List all gigs
- GET /api/gigs/:id - Get single gig
- PATCH /api/gigs/:id - Update gig status (admin)
- GET /api/gigs/creator/:creatorId - Get creator's gigs
